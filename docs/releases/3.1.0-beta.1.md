**Beta preview — real-data accuracy has not been validated.** The private extraction benchmark is **NOT RUN (dataset pending)**. Neither the e-Archive nor the OKC Z-report/UTTS accuracy gate has passed. No real-data accuracy scores are available, and passing synthetic tests or model connectivity checks does not establish extraction accuracy.

Our next milestone is to complete the private benchmark as soon as the human-reviewed dataset is ready, fix any findings, and publish the stable **3.1.0** release after both document-family gates and the remaining release checks pass. There is no confirmed publication date; this beta is not a promise of a benchmark pass.

These downloads are **unsigned beta test builds for manual use**, not verified production updates. The signing identity and real signed-installation validation remain pending. SHA-256 checksums detect corrupted downloads; they do not authenticate a publisher. Stable update discovery continues to exclude prereleases, and signature verification is unchanged.

Keep original financial documents, reviewed labels, API credentials and raw telemetry local. Review and approve every document before export. Unreadable values must remain blank/null with a review flag; never treat a plausible value as verified.

## What is available

- Native Windows egui/eframe desktop over the shared Rust core.
- Taxpayer/template selection, multiple-file import and e-Archive, OKC Z-report and UTTS review.
- Source preview, editable fields/tax rows, evidence highlights when available and individual correction/approval.
- Approved-document management, local retention/backups and Excel/CSV/JSON export.
- Background processing and local model setup through the bundled server companion.
- Clear external-destination disclosure and consent before optional remote inference.

## Download and run

Download the unsigned Windows x86_64 ZIP and compare its SHA-256 with the accompanying checksum file. Extract all files together to a new directory and launch `fatrocu.exe`. The package includes the matching server and updater helpers; no separate CLI installation is required. The unsigned beta is for manual testing and cannot be installed through the verified stable-update path.

Install Poppler `pdftoppm` on PATH for PDF previews and scanned-PDF inference; `pdftotext` is optional for word coordinates. Model setup downloads llama.cpp, Qwen3.5-4B and its projector outside the installation. No model weights, runtime archives or financial documents are bundled. See the matching [CLI](https://github.com/Fatrocu/fatrocu-cli/releases/tag/3.1.0-beta.1) and [server](https://github.com/Fatrocu/fatrocu-server/releases/tag/3.1.0-beta.1) releases for automation and terminal setup.

## Validation and remaining work

Native Windows formatting, test compilation and Clippy run on the beta source branch; release builds include the pinned core and server. Existing synthetic native-UI checks exercised import, review, correction, individual approval and an export action. The core verifies export contents; the native save-dialog artifact path was not independently confirmed. No real-data extraction accuracy is claimed.

Telemetry stores only its preference; package collection and purge await the user decision. Confirmed publisher signing, real signed installation and hosted OpenWiki publication also remain pending.
